В C++ char — это 8-битное целое число. std::cout << a выводит не число, а символ, который соответствует этому числу в таблице кодов.

## Первая часть программы 

```python

```

В a записан код символа 'a', то есть 97.

```python
a = a + 10;          # 97 + 10 = 107 это символ k 
```

```python
std::cout << a;      # Выводится k
```

## Вторая часть программы 

```python
a = a + 250;          # 107 + 250 = 357
```

Сейчас в a лежит 107. Прибавляем 250.Но char в C++ обычно 8-битный. В него помещаются значения от 0 до 255.
Число 357 не помещается. Лишняя часть отбрасывается 357 - 256 = 101. Код 101 — это символ 'e'.

### Задание 4

```python
a = 'a'
a = chr(ord(a) + 10)
print(a, end='')

a = chr(ord(a) + 250)
print(a, end='')
```

Результат:

```text
kť
```

Python int не ограничен 8 битами. Там число 357 не переполняется, а остаётся 357. А функция chr(357) берёт код 357 из таблицы Unicode. В Unicode код 357 — это символ ť. То есть в C++ char — 8 бит, поэтому 357 превращается в 101 → 'e', а в Python int — большой, поэтому 357 остаётся 357 → chr(357) → 'ť'

### Задание 5

Для 16-битного `unsigned short`: `2^16 = 65536`

1) x = 40000

2) y = x + x это 40000 + 40000 = 80000. Так как y unsigned short и число 80000 больше 65535. Вычитаем: 80000 - 65536 = 14464.
y = 14464

3) z = x * 2 это 40000 * 2 = 80000. Правило то же самое. z = 14464

4) y = y - x это 14464 - 40000 = -25536. Число получилось отрицательным. Прибавляем 65536: -25536 + 65536 = 40000. y = 40000.

5) z = z / 2 это 14464 / 2 = 7232. z = 7232.

В первом случае выполняются сложение, а затем вычитание. Сложение приводит к переполнению и потере старшей части. Однако следующее за ним вычитание уменьшает результат на ту же величину, которая была добавлена. Поскольку вычитание полностью компенсирует сложение, итоговое значение возвращается к исходному. Потеря старшей части не играет роли, так как операции взаимно уничтожают друг друга.

Во втором случае выполняются умножение, а затем деление. Умножение также вызывает переполнение, и старшая часть числа теряется безвозвратно. Деление выполняется уже над изменённым, усечённым числом. Оно делит то, что осталось, но не может вернуть то, что было потеряно. Так как деление не компенсирует потерю старшей части, исходное значение не восстанавливается.
