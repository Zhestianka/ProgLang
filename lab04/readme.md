### Задание 3

В C++ char — это 8-битное целое число. std::cout << a выводит не число, а символ, который соответствует этому числу в таблице кодов.

```python
char a = 'a'; # записан код символа 'a', то есть 97
a = a + 10;  # 97 + 10 = 107 это символ k 
std::cout << a; # Выводится k
a = a + 250; # 107 + 250 = 357. В него помещаются значения от 0 до 255. Лишняя часть отбрасывается 357 - 256 = 101. Код 101 — это символ 'e'
std::cout << a; # Выводится e
```

### Задание 4

```python
a = 'a'
a = chr(ord(a) + 10)
print(a, end='')

a = chr(ord(a) + 250)
print(a, end='')
```

Результат:

```text
kť
```

Python int не ограничен 8 битами. Там число 357 не переполняется, а остаётся 357. А функция chr(357) берёт код 357 из таблицы Unicode. В Unicode код 357 — это символ ť. То есть в C++ char — 8 бит, поэтому 357 превращается в 101 → 'e', а в Python int — большой, поэтому 357 остаётся 357 → chr(357) → 'ť'

*Объясните работу фрагмента программы на С++. В частности, почему* $x+x-x=x$, *но при этом*
$(x\cdot 2)/2\neq x$? *В отчете надо привести вычисления, приводящие к ответу.*

### Задание 5

Для 16-битного `unsigned short`: `2^16 = 65536`

1) x = 40000

2) y = x + x это 40000 + 40000 = 80000. Так как y unsigned short и число 80000 больше 65535. Вычитаем: 80000 - 65536 = 14464.
y = 14464

3) z = x * 2 это 40000 * 2 = 80000. Правило то же самое. z = 14464

4) y = y - x это 14464 - 40000 = -25536. Число получилось отрицательным. Прибавляем 65536: -25536 + 65536 = 40000. y = 40000.

5) z = z / 2 это 14464 / 2 = 7232. z = 7232.

### Задание 6 **(2)**

*Объясните работу фрагмента программы на С++. Если имеет место переполнение, 
то требуется найти точный ответ до запуска программы, а только потом сверить его с выводом.
В отчете надо привести вычисления, приводящие к ответу.*
```
std::cout << 2000000000 + 1000000000 << std::endl;
std::cout << 2000000000U + 1000000000U << std::endl;
std::cout << 2500000000U + 2500000000U << std::endl;
std::cout << 2500000000LL + 2500000000LL << std::endl;

```

### Задание 5

1) Оба литерала имеют тип `int`. `2000000000 + 1000000000 = 3000000000`. Для 32-битного знакового типа: `3000000000 - 2^32 = -1294967296`

2) `2000000000 + 1000000000 = 3000000000`. Переполнения нет.

3) `2500000000 + 2500000000 = 5000000000`. По модулю `2^32`: `5000000000 - 4294967296 = 705032704`

4) `LL` задаёт тип `long long`. При типичной 64-битной разрядности переполнения нет: `2500000000 + 2500000000 = 5000000000`

5) `20000 * 200000 = 4000000000`

6) `200000 * 200000 = 40000000000`. По модулю `2^32`: `40000000000 mod 4294967296 = 1345294336`

###  Задание 9 **(2)**
