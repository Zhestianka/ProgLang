### Задание 1 **(3)**
* **Тип в программировании** — атрибут объекта данных, задающий множество допустимых значений и методы работы с ними.
* **Статическая типизация** — тип объекта данных определяется в момент трансляции программы.
* **Динамическая типизация** — тип объекта данных определяется во время выполнения программы, при создании или присваивании значения.
* **Преобразование типа** — метод, преобразующий значение одного типа в такое же или близкое значение другого типа.
* **Каламбуром типизации** называется ситуация, когда одна ячейка данных рассматривается как две переменные разных типов.
* **Ошибкой согласования типа (type error)** называется использование значения одного типа в контексте другого типа.
* **Неявная типизация** — тип определяется автоматически по тексту программы, без явного указания типа.
* **Явное преобразование типа** — преобразование, которое явно указано в программе вызовом функции или специальной операцией.
* **Неявное преобразование типа** — преобразование, которое явно не записано в программе, но автоматически выполняется транслятором.
* **Сильная типизация** — типизация, при которой язык содержит мало или почти не содержит правил неявного преобразования типов.
* **Слабая типизация** — типизация, при которой язык содержит много правил неявного преобразования типов и допускает каламбуры типизации.

#### Пример 1 — Использование целого числа в качестве логического условия `int` в `bool`

**C++:**
```cpp
#include <iostream>

int main() {
    int n = 5;
    if (n) {
      std::cout << "" << std::endl;
    }
    return 0;
}
```

Программа компилируется: В С++ любое нулевое значение интерпритируется как `true`.

**Java:**
```java
public class Main {
    public static void main(String[] args) {
        int n = 10;
        if (n) {
          System.out.println("")
        }
    }
}
```

В Java `int` нельзя неявно преобразовать в `boolean`. C++ автоматически приводит числовой тип `int` к `bool`. Java требуетб чтобы условие в операторах `if`, `for` и `while` строго являлось `boolean`.

#### Пример 2 — Сложение логического и числового значений `bool` и `int`

**C++:**
```cpp
#include <iostream>

int main() {
    bool a = true;
    int b = 100;

    int c = a + b
    std::cout << c << std::endl;

    return 0;
}
```

`true` неявно преведется к 1.

**Java:**
```java
public class Main2 {
    public static void main(String[] args) {
        boolean n = true;
        int b = 100;
        int c = a + b;
    }
}
```

В С++ `bool` фактически является числовым типом с размером 1 байт, где true = 1, false = 0. В java тип boolean aбстрагирован от чисел и не участвует в арифметических операциях.  

#### Пример 3 — Неявное сужающее приведение `double` в `int`

**C++:**
```cpp
#include <iostream>

int main() {
    double pi = 3.14159;
    int a = pi;
    std::cout << a << std::endl;
    return 0;
}
```

Дробная часть неявно отбрасывается.

**Java:**
```java
public class Main3 {
    public static void main(String[] args) {
        double pi = 3.14159;
        int a = pi;
    }
}
```

C++ допускается неявное протерянное приведение типов с возможной потерей точности. Java запрещает неявное приведение с потерей данных и требует явного приведения типа.

*Используя* **typeid**, *найдите типы переменных* **a** и **b**. *Объясните результат.*

```cpp
#include <iostream>
#include <typeinfo>

int main() {
    bool x = true, y = false;

    auto z = x + y;
    std::cout << typeid(z).name() << std::endl;

    return 0;
}
```

Переменная z относится к типу `int`.

Поскольку оператор `+` — арифметический, перед его выполнением значения типа bool подвергаются целочисленному продвижению и преобразуются в `int`: `true` становится 1, а `false` — 0. Таким образом, выражение x + y по сути сводится к сложению 1 + 0, результатом которого является 0 типа `int`.

Так как z объявлена с использованием `auto`, компилятор сам определяет её тип, опираясь на тип выражения справа, — в данном случае это `int`.

Если вызвать typeid(z).name(), будет выведено i — это внутреннее обозначение типа `int` в данной реализации.

### Задание 6 **(2)**

Рассмотрите следующий фрагмент программы. 
```
int a = -1, b = 1;
unsigned int c = 1;
std::cout << a*b << std::endl;
std::cout << a*c << std::endl;
```
* *Объясните работу этой программы, используя правила неявного преобразования типов*
* *Что произойдет, если тип* **int** *заменить на* **short**, а **unsigned int** на **unsigned short**?*

Вывод:

```
-1
4294967295
```

1. Первое выражение: `a * b`

Обе переменные имеют тип `int`,  так что никаких преобразований не требуется: `-1 * 1 = -1`.

2. Второе выражение: `a * c`

В этом случае один операнд — `int`, а другой — `unsigned int`, причём их размеры совпадают. Знаковый `int` преобразуется в `unsigned int`.

В итоге -1 принимает значение, равное максимуму для unsigned `int`. Если `unsigned int` 32-битный, то это 2^32 - 1 = 4294967295.

Отсюда получаем: 4294967295 * 1 = 4294967295.

3. Если заменить типы на `short` и `unsigned short`

```cpp
short a = -1, b = 1;
unsigned short c = 1;
```

Перед выполнением арифметической операции оба типа предварительно приводятся к `int` — это возможно потому, что в типичной реализации C++ их диапазоны значений полностью укладываются в диапазон `int`.

Вывод:

```
-1
-1
```

Именно благодаря целочисленному продвижению до `int` значение -1 не преобразуется в `unsigned short`.

### Задание 7 **(2)**
*Рассмотрите следующий фрагмент программы.*
```
int x = 7, y = 4;
long double d = 0.25;
cout << (x / y) / d << endl;
cout << (x / d) / y << endl;
long a = 200000, b = 200000;
long long c = 200000;
std::cout << (a * b) * c << std::endl;
std::cout << a * (b * c) << std::endl;
```
*Почему изменения порядка действий приводит
к изменению результата? Объясните работу этой программы, используя правила неявного преобразования типов*

**Первая часть**:

```cpp
int x = 7, y = 4;
long double d = 0.25;

std::cout << (x / y) / d << std::endl;
std::cout << (x / d) / y << std::endl;
```
1. В первом выражении сначала выполняется `x / y`. Оба операнда имеют тип `int`, поэтому выполняется целочисленное деление 7 / 4 = 1. Затем 1 / 0.25 = 4.
2. Во втором выражении сначала вычисляется `x / d` . x автоматически преобразуется в `long double` 7 / 0.25 = 28. Затем 28 / 4 = 7.
Следовательно, порядок действий влияет на момент преобразования типов: в первом случае дробная часть теряется ещё при 7 / 4, во втором — деление сразу происходит в long double.

**Вторая часть**:

```cpp
long a = 200000, b = 200000;
long long c = 200000;

std::cout << (a * b) * c << std::endl;
std::cout << a * (b * c) << std::endl;
```

Здесь результат зависит от размера типа long на конкретной платформе Если `long` — 32-битный, как предполагается `a * b` сначала вычисляется как `long` `200000 * 200000 = 40 000 000 000` Это больше максимального значения 32-битного `long`, поэтому происходит переполнение уже на промежуточном умножении. После этого полученное значение участвует в умножении на `long long`.

Во втором варианте:

`b * c` сразу выполняется как `long long`, поэтому переполнения `long` нет. Затем a также приводится к `long long`, и вычисляется произведение в более широком типе. Если же `long` на платформе 64-битный, переполнения нет и оба выражения дадут одинаковый результат 8 000 000 000 000 000 000.

### Задание 8 **(2)**

*Для каких значений целочисленных переменных* **x**, **y** ,**z** *результатом
вычисления следующего выражения будет истина? Перечислите* **все** *случаи.
Объясните работу этой программы, используя правила неявного преобразования типов*

Дано выражение `(x == y) + (x == z) == true`. Каждое сравнение `x == y` и `x == z` дает bool. При сложении bool неявно преобразуется в int: `false` в 0, `true` в 1. Поэтому выражение фактически проверяет:

`(x == y ? 1 : 0) + (x == z ? 1 : 0) == 1`

Чтобы результат был true, сумма должна быть равна 1. Значит, ровно одно из двух сравнений должно быть истинным. Все случаи:

`x == y и x != z;`
`x == z и x != y;`

При x, y, z являющимися целыми числами. Других случаев нет.

### Задание 9 **(2)**

*Проверьте работу логического выражения*
```
x==y==z
```
*в языках* **Python**, **Java**, **C++** *для
целочисленных переменных* **x**, **y**, **z**.
*Объясните результат для каждого из языков.*

В Python это цепочечное сравнение `x == y == z` эквивалентно `(x == y)` and `(y == z)`. Поэтому выражение истинно тогда и только тогда, когда `x = y = z`.

В Java сравнение выполняется слева направо. После первого сравнения `x == y` получается значение типа `boolean`. Затем программа фактически пытается сравнить этот `boolean` с z, имеющим тип `int (x == y) == z`. Такое сравнение недопустимо, поэтому программа не компилируется.

В C++ выражение также разбирается слева направо `(x == y) == z`. Результат `x == y` имеет тип `bool`. При сравнении с `z bool` преобразуется в целое значение по принципу `false` в 0, `true` в 1.

Поэтому выражение фактически проверяет `(x == y ? 1 : 0) == z` Оно истинно в двух случаях `x == y и z == 1 или x != y и z == 0`.
